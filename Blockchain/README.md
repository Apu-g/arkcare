# CareQuest local blockchain

This package is ArkCare's zero-cost judge/demo blockchain rail.

## Linux

From the repository root:

```bash
bash scripts/start-blockchain-demo.sh
```

## Windows

```bat
scripts\start-blockchain-demo.cmd
```

The launcher installs blockchain dependencies when needed, starts a local Hardhat
EVM at `127.0.0.1:8545`, deploys the CareQuest contracts, runs contract smoke
tests, then starts the ArkCare bridge at `127.0.0.1:8546`.

For the Next.js local environment:

```env
CAREQUEST_BLOCKCHAIN_ENABLED=true
CAREQUEST_BLOCKCHAIN_BRIDGE_URL=http://127.0.0.1:8546
```

## Contracts

- `CareQuestCapsule.sol`: legacy zero-decimal, non-transferable CAP contract.
- `CareQuestHospitalCapsules.sol`: non-transferable multi-token hospital
  Capsule contract. The seeded demo uses token ID `1001` for CITY and `1002`
  for LOTUS.
- `CareQuestAuditAnchor.sol`: separate Merkle-root audit commitment contract.

The database CapsuleAward ledger remains authoritative. The EVM is a local
development blockchain, not a decentralized public network.

Phone/wearable synchronization, proof-of-work mining, mining-pool output and
public token value shown in the product are explicitly simulated concept layers.
They are not generated by these contracts.

No patient names, identifiers, diagnoses, report contents, medicines or
health-event descriptions should be written to the chain.
